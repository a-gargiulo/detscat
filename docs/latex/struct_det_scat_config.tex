\doxysubsection{Detailed Description}
Structured data container for configuration file parameters. 

This struct stores all required user input parameters, as defined in the configuration file. It serves as a central container for accessing parsed configuration values throughout the application.

See \doxysectlink{config_file_format}{Configuration File Format}{0} for details on the expected configuration format.
